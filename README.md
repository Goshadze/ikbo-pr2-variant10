# Depgraph

Граф зависимостей пакетов Ubuntu (Rust, apt).
Практическая работа № 2 по конфигурационному управлению, вариант 10.

## Описание

Загружает зависимости из репозитория Ubuntu или тестового файла
и обходит их в ширину, начиная с заданного пакета.

Выполнены этапы 1–3.

## Функции

- Разбор коротких и длинных параметров; для длинных поддерживается `--name=value`.
- Сообщения об ошибках: неизвестный или повторный параметр, отсутствие значения,
  пустая строка, недопустимый режим, неверный URL или отсутствующий файл.
- Вывод всех параметров в формате `ключ=значение`.
- Чтение `Packages.gz` напрямую по HTTP, три попытки загрузки при ошибке.
- Разбор `Package`, `Depends`, `Pre-Depends` и строк продолжения.
- BFS без рекурсии; общие зависимости посещаются один раз, циклы допустимы.
- Фильтр исключает пакеты, содержащие подстроку, и пути через них.
  Регистр учитывается; исключение начального пакета считается ошибкой.
- Чтение тестового файла; неверная строка сопровождается её номером.

## Настройки

Параметры командной строки:

- `-p`, `--package NAME` — имя пакета (обязательно)
- `-r`, `--repo URL_OR_PATH` — адрес репозитория или тестовый файл (обязательно)
- `-t`, `--test-mode MODE` — `url` или `file`, по умолчанию `url`
- `-o`, `--output PATH` — файл изображения, по умолчанию `graph.png`
- `-a`, `--ascii-tree MODE` — `on` или `off`, по умолчанию `off`
- `-f`, `--filter TEXT` — исключаемая подстрока; без параметра фильтра нет
- `-h`, `--help` — справка

Имя изображения и режим дерева пока только проверяются и выводятся.
Визуализация относится к этапу 5.

## Репозиторий Ubuntu

Используются Ubuntu 24.04 (`noble`), архитектура `amd64`, компоненты `main`
и `universe`. URL должен вести на корень репозитория с этими индексами;
завершающий `/` необязателен. Другие дистрибутивы не настраиваются.

Информация берётся из файлов индекса. Менеджеры пакетов и библиотеки
получения зависимостей не вызываются. `ureq` отвечает за HTTP, `flate2` — за gzip.
Ограничения версий отбрасываются, альтернативы через `|` включаются все.
`Recommends`, `Suggests` и разрешение виртуальных пакетов через `Provides`
не поддерживаются. Результат описывает индекс, а не точный план установки apt.

## Тестовый репозиторий

Текстовый файл, по одному пакету в строке:

```text
# A зависит от B и C
A: B C
B: D
C: D
D:
```

Имена — заглавные латинские буквы. Пустые строки и строки с `#` в начале
пропускаются. Пакет, упомянутый только справа, считается узлом без зависимостей.

## Запуск

Требуется Rust с Cargo.

```sh
cargo build --release
cargo test
./run.sh
```

`run.sh` собирает проект и запускает пример. Справка:

```sh
./target/release/depgraph --help
```

## Примеры

Порядок пакетов после строк с параметрами:

```sh
./target/release/depgraph -p A -r tests/fixtures/diamond.txt -t file
# A, B, C, D — общая зависимость D посещена один раз
./target/release/depgraph -p A -r tests/fixtures/cycle.txt -t file
# A, B — цикл не зацикливает обход
./target/release/depgraph -p A -r tests/fixtures/filter.txt -t file -f AB
# A — пакеты с подстрокой AB исключены
```

Ошибки (сообщения выводятся в stderr, код выхода — 1):

```sh
# Не указан пакет
./target/release/depgraph --repo https://example.com/
# Неверный адрес репозитория
./target/release/depgraph -p curl -r ftp://example.com/
# Неверный тестовый режим
./target/release/depgraph -p curl -r https://example.com/ -t auto
# Пустое имя изображения
./target/release/depgraph -p curl -r https://example.com/ -o ''
# Неверный режим дерева
./target/release/depgraph -p curl -r https://example.com/ -a yes
# Пустой фильтр
./target/release/depgraph -p curl -r https://example.com/ -f ''
```

```sh
# Пакет отсутствует
./target/release/depgraph -p Z -r tests/fixtures/leaf.txt -t file
# Некорректная строка тестового файла
./target/release/depgraph -p A -r tests/fixtures/invalid.txt -t file
```
